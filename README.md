# Under the Hood of Agentic AI

Slide deck for Sam Bourton's talk at Signal Geneva, 18 September 2026.

The deck is a single self-contained HTML file: `2026-09-17 - Signal Geneva - deck v9.html`. No build step, no dependencies, works offline.

## Presenting

- Open the HTML file in a browser and press `F` for fullscreen present mode.
- Arrow keys, space or a clicker step through slides. `Home` and `End` jump to the first and last slide.
- `N` toggles the speaker notes drawer. `Esc` closes it.
- `T` on slide 6 switches the heat-map colour scale. `1` to `5` on slide 9 toggle the cluster rings.

## Versioning

Each revision is a new file (`... deck v10.html`, and so on). The title-slide notes carry a one-paragraph changelog for the current version.

See `CLAUDE.md` for the internal structure of the deck.
